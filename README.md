# oroma-alfred/homebrew-tap

Homebrew formulae for [phpwarden](https://phpwarden.io), an open-source PHP vulnerability scanner
for Composer, WordPress and the PHP engine, ranked by real-world exploitation (CISA KEV, then EPSS).

```bash
brew install oroma-alfred/tap/phpwarden
phpwarden --version
```

Source: https://github.com/oroma-alfred/phpwarden (Apache-2.0)
